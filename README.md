![Convex](https://img.shields.io/badge/Convex-orange?style=for-the-badge)

SkillSync is a **real-time remote coding interview platform** that enables candidates and interviewers to conduct collaborative technical interviews with video calls, screen sharing, coding, and evaluations.

## ✨ Features

- 🎥 Real-time video & audio interviews
- 🖥️ Screen sharing & recording
- 💻 Collaborative coding with Monaco Editor
- 🌐 Multi-language code support
- 📅 Interview scheduling
- 👥 Role-based candidate & interviewer workflows
- 💬 Comments & reactions
- 📊 Candidate evaluations
- ⚡ Real-time database operations

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Backend:** Convex
- **Authentication:** Clerk
- **Video:** Stream Video SDK
- **Styling:** Tailwind CSS
- **Editor:** Monaco Editor

## ⚙️ Run Locally

```bash
git clone https://github.com/your-username/skillsync.git
cd skillsync
npm install
npm run dev
```

Create a `.env.local` file with your **Clerk, Convex, and Stream** credentials.

Open `http://localhost:3000` in your browser.
